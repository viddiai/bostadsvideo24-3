# Bostadsvideo 24.2

Landningssida för Bostadsvideo24 — proffsig bostadsvideo levererad inom 24 timmar.

Statisk sida utan byggsteg: öppna `index.html` direkt eller servera mappen med valfri webbserver.

## Struktur

- `index.html` — hela sidan
- `assets/css/style.css` — stilmall med designvariabler och responsivitet
- `assets/fonts/` — Bricolage Grotesque (variabelt typsnitt, lokalt för GDPR och prestanda)
- `assets/img/` — bilder (JPEG för webben, PNG-original)
- `Bostadsvideo24 Landningssida.html` — rå designexport från Claude Design (källa)

## Integrationer

- **Bokning:** Cal.com-popup på alla "Boka en demo"-knappar (`stefan-vikstrom-peakmarketing/strategimote-bostadsvideo24`)
- **Video:** Bunny Stream, bibliotek 699355

## Att göra

- Ersätt platshållare: kontorsloggor och "wall of love" (omdömen/skärmdumpar)
- Prissektionens "50 % rabatt hela juli" är datumkänslig
